## Терминология

| פיגור שכלי, מפגר | מוגבלות שכלית התפתחותית | 25 раз: статьи 855, 1055, страница «סנטוריום» |
| חוסים, חוסה, מוסד חוסים | דיירים ודיירות / מקבלי שירות | 30 раз: статьи 1039, 1045 и др. |

| הסובלים מ… | אנשים עם… | 18 раз |
| חניכים (о взрослых) | דיירים ודיירות / משתתפים | 5 раз |
| מוסד | מעון, בית, מסגרת | Около 53 раз (с ложными срабатываниями) |
| מש"ה (сокращение в публичном тексте) | Полный термин при первом упоминании | 7 раз |

SEO: старые статьи собирают трафик по запросам вроде «מעון לבעלי צרכים מיוחדים». Рекомендация: **слаги сохранить** (URL не меняются), а H1, заголовки и тексты переписать уважительно. В meta description можно один раз нейтрально упомянуть распространённый поисковый оборот, если клиент согласится.

## Чувствительный контент: решить до переноса

1. **Запись 1234 «פסק דין … בגין הוצאת דיבה»** называет по имени частное лицо, бывшего сотрудника, и называет его «הנוכל». Рекомендация: **не переносить** без решения клиента и юриста. Это риски по приватности и тону, а суть «есть решение суда в нашу пользу» при необходимости можно изложить без имени. Если запись снимают — 410 или 301 на «חדשות ועדכונים», строка уже есть в `redirects.csv`.

## Редиректы ([redirects.csv](redirects.csv), [redirects-attachments.csv](redirects-attachments.csv))

**Политика.** Постоянные ссылки — «Название записи» (`/%postname%/`, как сейчас), **все слаги сохраняются**. Поэтому 15 страниц, 19 статей и 2 рубрики остаются по тем же адресам (HTTP 200, редирект не нужен). Это самый безопасный вариант для SEO.

| Тип | Строк | Действие |
|---|---:|---|
| Страницы | 15 | keep (200) |
| Записи | 19 | keep (200); запись 1234 — по решению клиента (410 или 301) |
| Рубрики | 3 | 2 keep; пустая «כללי» → 301 на «חדשות ועדכונים» |
| Метка с устаревшим термином | 1 | 301 на архив статей |
| Битая ссылка `/תעסוקה/` (с главной, сейчас 404) | 1 | 301 на «מעון ראשי – בית לחיים» |
| Новая страница «הצהרת נגישות» | 1 | new |
| Страницы вложений | 494 | 301 на страницу, где используется изображение, иначе на галерею |

- В каждой строке путь дан в двух видах — в кодировке UTF-8 и percent-encoded, потому что панель uPress («הפניות») может требовать любой из них.
- **Файлы `/wp-content/uploads/YYYY/MM/…`** сохраняют свои пути, если медиатека переносится импортом WXR: файлы попадают в те же папки по дате. Тогда внешние ссылки на картинки не ломаются.
- Сейчас канонический домен — **www**.nevehairus.com: `nevehairus.com` отдаёт 301 на `www`. При переезде оставляем `www`, чтобы не менять канонические URL.
