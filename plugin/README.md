# Плагин виджетов (шаг 3) — ещё не начат

По плану работ шаг 3 начинается **после одобрения прототипа**, а ставить плагин на тестовый сайт можно **только после решения вопроса с ботом uPress «סוכן וורדפרס»**.

## Что войдёт (черновой состав по прототипу v3.1)

Префикс всех классов, функций и хуков — `nh_` / `NH_` / `nh-`. Каждый текст, фото и ссылка — поле в редакторе, **у каждого текста — пара полей «обычный текст / בשפה פשוטה»** (иначе простой вариант где-нибудь потеряется).

1. **Буква с комнатой** — общий PHP-компонент: порт `letter_room()` из `scripts/build_prototype_html.py` + `letters.json` (контуры при весах 800/300, «комнаты», режим `whole` для работ жильцов), картинка из медиатеки как AVIF+WebP `<picture>` с правильным `sizes`. Используется виджетами ниже.
2. **Обложка** «בית. לחיים.» (ב закреплена, пока худеет; 150svh только при движении).
3. **Индекс домов** и **быстрый выбор**.
4. **День в четырёх глаголах** с «отпечатками».
5. **Ладонь כ** (работы жильцов, цветовые кредиты) и **круги ס** (мандала целиком, кольца по работе).
6. **Годы**, **голоса** (цитата + видео-фасад с согласием), **шаги**, **ל-вакансии**.
7. **Дверь ד** — широкая буква с формой визита в проёме; формы: `wp_mail`, nonce, honeypot, ловушка по времени, лимит частоты, согласие, уведомление §11; вложение-резюме не попадает в медиатеку.
8. **Модуль плагина (не виджет):** панель «תצוגה» и режимы (простой язык, спокойный, без движения), баннер cookies, панель визита на телефоне.

### Что учесть при переносе (из технического ревью v3)

- **Не опираться на структуру DOM.** Elementor вставляет свои обёртки (`div.elementor > div.e-con`) между `<main>` и разворотами. Развороты ищутся по атрибутам (`[data-running]`), не по `main > section` — так уже сделано в прототипе; в Elementor атрибут ставит наш контейнер-«разворот» (или Custom Attributes в Pro).
- **Встроенный скрипт из `head.html`** (режимы до первой отрисовки, `pagereveal`) печатается в `wp_head` до стилей и исключается из «отложить/объединить JS» в плагинах кэша.
- **Имена переходов между страницами** уникальны для записи (`home-bet-{post_id}`) и ставятся скриптом только для одного пути (строка индекса → страница дома). Page Transitions из Elementor Pro не включаем.
- **CSS по виджетам:** в прототипе один `site.css`; в плагине стили регистрируются отдельно и грузятся только на страницах с виджетом. Старые компоненты v1 лежат отдельно в `prototype/assets/css/legacy-v1.css` и не переносятся.
- GSAP не нужен: v3 обходится своим кодом (v3.js ≈ 13 КБ + site.js ≈ 21 КБ, ≈ 12 КБ по сети) и CSS.

## Архитектура (по [research/04](../research/04-tech-elementor-wp-upress.md))

- Классический `\Elementor\Widget_Base` + `elementor/widgets/register`, своя категория. Официального API для собственных атомарных V4-виджетов нет.
- Скрипты и стили регистрируются через `wp_register_*` и подключаются через `get_script_depends()` / `get_style_depends()`, то есть **только на страницах с виджетом**.
- Сторонних библиотек нет; если понадобятся — только локально в плагине, без CDN, с сохранёнными копирайт-заголовками.
- Цвета и шрифты привязаны к Global Colors/Fonts, куда синхронизируются V4-переменные.
- Каждый виджет проверяется в редакторе V4 на тестовом сайте.
