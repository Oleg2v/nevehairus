# v4.1 home page — «more life» (Itzik, 17.11.2026)

The contract for the second pass on the v4 home. It extends research/09-v4-home-spec.md: every rule there still
holds unless this file changes it. Itzik's verdict on v4: too static and empty, it needs life.

## 0. Rules (unchanged unless stated)

- **Sites.** Only the TEST site. The live site is read-only. No new plugins. Elementor's own classic widgets on the
  pages; site-wide code in the child theme.
- **Texts.** Texts come from the live site word for word. The section titles Oleg gave are allowed:
  - «החיים בנווה האירוס»;
  - «מקצועיות, ניסיון ויחס אישי»;
  - the four item labels of §1.5;
  - «נשמח שתבואו להכיר אותנו».

  UI labels are allowed too («להמשך קריאה», «קרא עוד», «WhatsApp»). No new facts, numbers, names or stories.
- **Plain language.** Twins for every new text block, drafts, fact-checked.
- **Photos.** Real photos from the live media library only, never stock. No recognizable faces unless the live site
  already shows that very photo with them.
- **Accessibility.** WCAG 2.1 AA / IS 5568 everywhere, in every state: header transparent and solid, plain mode,
  the accessibility options.
- **Motion — changed; now allowed, soft:**
  - blocks fade in and rise gently once when scrolled into view;
  - the hero photo zooms in very slowly, once;
  - cards lift on hover;
  - the header turns solid on scroll.

  Nothing blinks, pops, loops, bounces, parallaxes or slides sideways. Under `prefers-reduced-motion: reduce` and with
  the accessibility option «עצירת אנימציות» there is no animation and no transform transition at all: everything is
  simply shown.
- **Layout.** No empty side margins. Every section's background runs the full width. Content sits in a 1320px column
  with 20/32/40px gutters (phones/tablets/desktop); the hero, the life photo and the footer run edge to edge.
- **Colours** only from the logo palette (research/09 §1), plus:
  - night #1C1830 for the footer;
  - green-700 #2F6B2A, white on it 6.4:1, for the WhatsApp button and the contact band's buttons.

### 1.1 hero (full screen)

  The white text must reach 4.5:1 on its darkest neighbour pixel: measure it on the real photo at 390, 768 and 1440.

## 3. Motion (child theme)

- **Fade-in:** `nh-reveal` on section inner containers, cards, the pro items, the video items and the years.
  - With JS on (`html.nh-js`), an element starts at `opacity: 0; translate: 0 24px`.
  - An IntersectionObserver (threshold .15, rootMargin -5% bottom) adds `is-in` once: opacity 1, translate 0, 600ms
    cubic-bezier(.2,.7,.2,1).
  - Siblings in a grid stagger by 80ms (nth-child up to 4).
  - Elements already in view on load are shown at once, without the transition.
- **Never hidden:**
  - without JS;
  - under `prefers-reduced-motion: reduce`;
  - with `html.nh-a11y-still`;
  - in the Elementor editor;
  - when printing.
- **Hero zoom:** see §1.1.
- **«עצירת אנימציות» (new option in the accessibility panel, `aria-pressed`, stored in `nh-a11y`):** sets
  `html.nh-a11y-still`. That means:
  - no animations;
  - no transitions of transform or opacity;
  - the hero photo at scale 1;
  - every `nh-reveal` shown.

  Reset clears it. `prefers-reduced-motion: reduce` does the same without the option.
