# Копия версии v4.2 тестового сайта (18.11.2026)

Снята перед переделкой главной в v4.3 по замечаниям Ицика: форма, cookies, «הבית שלנו», кремовый фон. Нужна, чтобы
при необходимости вернуть v4.2. Более ранние копии:
- v4: [../2026-11-17-v4](../2026-11-17-v4/README.md);
- v3.2: [../2026-11-17-v3.2](../2026-11-17-v3.2/README.md).

## Что сохранено

**На тестовом сайте** — черновики-копии, нигде не показываются:

| Оригинал | Копия (черновик) |
|---|---|
| #32 «דף הבית» (главная v4.2) | **#106** |
| #86 шапка v4 (Theme Builder) | **#107** |
| #87 полоса внизу v4 (Theme Builder) | **#108** |
| #88 «פרטי קשר — בלוק משותף» (общий блок контактов) | **#109** |

- Данные Elementor в копиях совпадают с оригиналами: проверено при снятии.
- У копий своя метка `_nh_snapshot_of` / `_nh_snapshot_label` («v4.2 (18.11.2026)»).
- Условия показа шапки и полосы в копиях выключены.
- Глобальные цвета и шрифты Elementor (Kit #4) лежат в записи `nh_backup_v42_kit`, остальные настройки — в `nh_backup_v42_options`.

**В репозитории** — [site-state.json](site-state.json), те же данные в JSON.

**Версии:** плагин 0.2.6, тема 1.3.3, Elementor и Pro 4.4.0, WordPress 7.1.4.

## Как вернуть v4.2

1. **Из кода.** Взять коммит `99b497d` в ветке `claude/upbeat-fermi-3acsyh`: тему 1.3.3 и `templates/v4/*.json`. Затем выполнить `python3 -I scripts/test_site.py theme --go` и `python3 -I scripts/test_site.py v4 --go`.
2. **Вручную в Elementor.** Открыть черновик #106, в «Навигаторе» выделить всё, скопировать, вставить в #32 и обновить. Так же перенести #107 в #86, #108 в #87 и #109 в #88.
