- **Живой сайт:** https://www.nevehairus.com — **не трогаем**. С него только читали публичные страницы (GET).

## Как посмотреть прототип

- **Без сервера:** `python3 -I scripts/build_standalone.py` → три файла в `prototype/standalone/` (главная, страница дома, дизайн-система), открываются двойным щелчком ([подробнее](prototype/README.md#как-открыть)).
- **С сервером:** `cd prototype` и `python3 -m http.server 8080`, затем http://localhost:8080/.
- **Кадры и видео:** [prototype/STORYBOARD.md](prototype/STORYBOARD.md), обзорные листы в [prototype/storyboard/](prototype/storyboard/) и видео прокрутки в [prototype/storyboard/video/](prototype/storyboard/video/).
- **На тестовом WordPress** — https://nevehairus.ussl.co.il/ после установки плагина и сборки страниц (шаги 3–4, идут сейчас).
- ⚠️ **Репозиторий публичный:** в нём временные фото с текущего сайта, работы жильцов и тексты клиента. Если это не нужно, лучше сделать его приватным (Settings → General → Danger Zone → Change visibility).

### Чек-лист: выполню сразу, как только будет доступ

1. **Бэкап.** Убедиться, что в uPress есть свежая копия (хранятся 30 дней). При необходимости попросить Олега сделать ручную. В панели uPress сами ничего не меняем.
2. **הגדרות → קריאה** → «בקשה ממנועי חיפוש שלא לאנדקס את האתר» ✔.
3. **הגדרות → קישורים קבועים** → «שם הפוסט» (`/%postname%/`).
4. **הגדרות → כללי** → אזור זמן «ירושלים».
5. **Тема — Hello Elementor** (по данным research/04, актуальная версия 3.5.2) **+ дочерняя `hello-theme-child`**; активировать дочернюю. Почему не своя минимальная тема: Hello — официальная «пустая» тема Elementor, весь макет (шапка, подвал, шаблоны) делается в Theme Builder Elementor Pro. Дочерняя тема даёт место для нашего CSS без риска потерять его при обновлении. Своя тема дублировала бы Hello без выигрыша. Hello Biz не берём: по research/04 он скоро перейдёт в режим поддержки.
6. **ezCache → режим разработки** (Dashboard → Development Mode). На тестовом сайте для этого есть REST-маршрут `/wp-json/ezcache/v1/dev-mode`. Перед сдачей вернуть обычный режим.
7. **Проверка** запуском `python3 -I scripts/test_site.py check`. Ожидаем: на главной `<meta name='robots' content='noindex, nofollow'>` (WordPress 7.1 больше не пишет `Disallow: /` в robots.txt), `/?p=1` даёт 301 на «красивый» URL, часовой пояс `Asia/Jerusalem`, тема `hello-elementor-child`. ✅ Выполнено 16.11.2026, см. журнал выше.

## Безопасность и правила

- **Секреты — только в `.env`**: он в `.gitignore`, шаблон — [.env.example](.env.example). `.mcp.json` тоже в `.gitignore`: туда Claude Code может записать токен MCP.
- На живой сайт отправлялись только GET-запросы для сбора контента.
- Тестовый сайт меняется только скриптами, каждое изменение — в журнале выше. В панели uPress ничего не менялось.
- На живой и тестовый сайты ничего не публиковалось, ни с кем не связывались. Внимание: GitHub-репозиторий публичный (см. «Как посмотреть прототип»).

## Порядок работы (решение Олега 19.11: «быстрый режим»)

- **Обычный круг правок:**
  1. правка;
  2. выкладка на тестовый сайт;
  3. один автоматический прогон: ширины экрана, axe, контраст;
  4. снимки на iPhone и компьютере;
  5. короткое сообщение Олегу на 5–10 строк.

  Без большого отчёта и без независимой проверки.
- **Перед показом Ицику** сайт проверяет сам Олег.
- **Большая независимая проверка** — только на финал страницы и перед переносом на живой сайт.
- **Только то, что просили.** Свои идеи — одной строкой как предложение, без правки.
- **От Ицика:** правки одним списком на страницу, фото — файлами, а не скриншотами.

## Структура репозитория

```
research/   исследование, концепции и решения жюри (шаги 1–2)
content/    тексты 15 страниц и 19 статей, photos.csv, redirects.csv, снимок REST
prototype/  прототип HTML/CSS/JS (v3) + живая копия v2, раскадровки, дизайн-система (шаг 2)
plugin/     исходники плагина и .zip (шаг 3, после одобрения)
templates/  JSON-шаблоны и глобальные настройки (шаг 4)
scripts/    воспроизводимые скрипты (см. ниже)
```

| Скрипт | Что делает |
|---|---|
| `scripts/check_test_site.py` | Публичная проверка тестового сайта (только GET; отказывается работать с живым доменом) |
| `scripts/extract_content.py` | Снимок живого сайта → Markdown, `index.csv`, `photos.csv` |
| `scripts/build_redirects.py` | `redirects.csv` и `redirects-attachments.csv` |
| `scripts/contrast.py` | Таблица контраста WCAG для токенов |
| `scripts/build_prototype_images.py` | Фото прототипа → AVIF/WebP, без метаданных |
| `scripts/build_prototype_html.py` | Сборка страниц прототипа из `prototype/src` (в том числе буквы-«комнаты» v3) |
| `scripts/build_letters.py` | Контуры букв ב כ ס ד ל ם из Frank Ruhl Libre при весах 800 и 300 и их «комнаты» → `prototype/assets/letters.json` |
| `scripts/build_standalone.py` | Одиночные HTML для просмотра без сервера (CSS, JS, шрифты и фото внутри файла) → `prototype/standalone/`, в git не попадают |
| `scripts/freeze_v2_snapshot.py` | Замороженная живая копия v2 в `prototype/v2/` |
