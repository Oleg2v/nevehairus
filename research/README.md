## Ключевые выводы, которые влияют на план

1. **Год «с 1985» не подтверждён**: источники дают 1973, 1985 и 1995. Нужен документ клиента. Год основания **1957** подтверждён реестром компаний.
2. **ת"י 5568 (ред. 2023) основан на WCAG 2.0.** Делаем по WCAG 2.2 AA, сохраняем валидную разметку (4.1.1) и выполняем израильский 2.4.10 на уровне AA. Видео нужны субтитры на иврите (1.2.2 на уровне AA).
3. **Elementor MCP встроен с 4.3.0**, но собирает только атомарные V4-элементы. Наши классические виджеты (`Widget_Base`) MCP не вставит, поэтому они ставятся в редакторе или через JSON-импорт. Официального API для собственных атомарных виджетов нет.
4. **uPress:**
   - REST API может быть выключен в настройках безопасности. Тогда MCP не заработает, нужно согласовать с Олегом.
   - Как работает «סוכן וורדפרס», в открытой документации **не найдено**. Это главный риск для шага 3.
5. **GSAP 3.15.1 бесплатен** (стандартная лицензия «No Charge»). Включать его в приватный плагин можно, если сохранять копирайт-заголовки.
6. **Cookies.** Прямого требования opt-in в израильском законе нет, но статистику и встраиваемые медиа включаем только по согласию. Уведомление по §11 обязательно рядом с каждой формой.
