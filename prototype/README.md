# Прототип — v2 «ב׳ — בית» (шаг 2)

Живой прототип главной и одной внутренней страницы (HTML, CSS, GSAP) плюс страница дизайн-системы. Иврит, RTL, WCAG 2.2 AA (ת"י 5568), `prefers-reduced-motion`.

> **v2 заменяет v1.** v1 («בית לחיים», тёплый редакционный шаблон) три независимых критика оценили в 5.3–5.6 по шкале Awwwards. v2 построена на одной идее: буква ב была рисунком дома. Разбор — в [research/03, раздел v2](../research/03-creative-directions.md#v2-после-отзыва-заказчика); кадры и анимации — в [STORYBOARD.md](STORYBOARD.md); кадры v1 — в [`storyboard/v1/`](storyboard/v1/).

| Страница | Файл | Что показывает |
|---|---|---|
| Главная | [`index.html`](index.html) | Вход в дом через букву ב, манифест под небом, три дома стопкой карточек, «בשפה פשוטה», целый день одним экраном, годы, Mandala Lock, голоса, вакансии, «4 шага», форма визита |
| Внутренняя: «מעון ראשי — בית לחיים» | [`program-main-home.html`](program-main-home.html) | Шаблон страницы программы: hero с аркой и переходом из карточки (View Transition), цифры, галерея с лайтбоксом, бенто, истории, форма визита |
| Дизайн-система v0.2 | [`design-system.html`](design-system.html) | Токены v1 + v2, живая проверка контраста, типографские регистры, компоненты v2 |

## Как открыть

Нужен любой статический сервер: шрифты и модули по `file://` браузер не загрузит.

```bash
cd prototype
```

```bash
python3 -m http.server 8080
```

Затем открыть http://localhost:8080/. Режим «меньше движения»: системная настройка *Reduce motion* или кнопка паузы в шапке («הפחתת תנועה באתר»; на телефоне — в меню).

## Структура

```
prototype/
├── index.html, program-main-home.html, design-system.html   ← СОБРАННЫЕ страницы (не править руками)
├── src/                                                     ← исходники страниц и partials (шапка, подвал, cookies, лайтбокс)
├── assets/
│   ├── css/tokens.css, main.css, v2.css   ← исходники; site.css — склейка + безопасная минификация (генерируется)
│   ├── js/site.js                 ← UI: меню, cookies, видео-фасад, лайтбокс, формы, тема шапки, «цвет = жизнь», мобильная панель
│   ├── js/motion.js               ← сцены на скролле (GSAP; грузится после load; не грузится при reduced motion)
│   ├── js/home.js                 ← годы «заливаются» цветом (без GSAP)
│   ├── vendor/gsap/               ← GSAP 3.15.1 + ScrollTrigger + SplitText, локально (лицензия: README-gsap.md)
│   ├── fonts/                     ← Frank Ruhl Libre + Assistant (OFL), подмножества core/latin + OFL.txt
│   └── img/                       ← 20 временных фото (+ мандала-кольцо): AVIF + WebP, 480–1440px, без EXIF/GPS; manifest.json с alt
├── storyboard/                    ← 53 кадра v2 + обзорные листы; v1/ — кадры и спецификация v1
├── _lab/                          ← черновые эксперименты v2 (не входят в прототип, см. _lab/README.md)
├── STORYBOARD.md                  ← раскадровка + спецификация каждой анимации
└── DESIGN-SYSTEM.md               ← токены, контраст (36 пар), шкалы, компоненты, перенос в Elementor
```

Сборка (Python 3, без зависимостей):

```bash
python3 -I scripts/build_prototype_html.py
```

Скрипт собирает `src/*.html` → `*.html`, склеивает и минифицирует CSS (проверено: все 678 правил совпадают с несжатой склейкой) и подставляет адаптивные `<picture>` из `assets/img/manifest.json`.

Фото пересобираются так (нужен Pillow; исходники — оригиналы с текущего сайта):

```bash
python3 -I scripts/build_prototype_images.py --src <папка_оригиналов> --out prototype/assets/img
```

## Что в прототипе временное

- **Фото** взяты с текущего сайта. Это кадры **без узнаваемых лиц**: интерьеры, сад, мозаика, люди со спины. Перед запуском их заменит съёмка с оформленными согласиями ([бриф](../research/03-creative-directions.md#бриф-на-фотосъёмку-нужна-до-запуска)).
- **Логотип** временно заменён типографским знаком «מעון נווה האירוס»: растровый логотип сайта мелкий и мутный. Нужна векторная перерисовка ириса, которую согласует заказчик.
- **Цитата мамы жильца** — дословно из страницы отзывов, без фамилии. Перед запуском нужно заново получить согласие на публикацию.
- Ссылки на ещё не сделанные страницы ведут на якоря главной.
- **Формы ничего не отправляют.** Это демонстрация валидации, сообщений и доступности. В WordPress отправка пойдёт через `wp_mail()` (шаг 3).
- Тексты на иврите — **предложение копирайта**: только подтверждённые факты, лексика по таблице терминов ([research/05](../research/05-compliance-a11y-privacy-licenses.md)): «התנהגות מאתגרת» вместо «קשיי התנהגות», без «יחס אישי», «לב גדול», «סבלנות», «עולה על כל דמיון».
- Уведомления о приватности у форм — **черновик для юриста**.

## Проверки v2

Проведены 15.11.2026 в этой среде: Chromium 1243 через Playwright, Lighthouse 12.8.2, axe-core 4.14.0.

**Доступность (axe-core):** теги wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa и best-practice. Прогон после полной прокрутки.

| Что проверено | Нарушений |
|---|---|
| 3 страницы × (десктоп, iPhone 13, reduced motion) | **0** (51–57 проверок пройдено) |
| Состояния: баннер cookies с настройками, запрос согласия на видео, форма со сводкой ошибок, лайтбокс, мобильное меню, мобильная панель «תיאום ביקור» | **0** |

**Клавиатура (скрипт Playwright, Tab по всей странице):** 299 остановок (главная и внутренняя; десктоп, iPhone, reduced motion), **0 проблем**. У каждой остановки видимое кольцо фокуса. Ни одна не перекрыта шапкой, мобильной панелью или баннером: проверено по `elementFromPoint`, с учётом слоёв. Скрытых или прозрачных элементов в фокусе нет.

**Lighthouse (мобильный профиль: медленный 4G, 4× CPU; локальный сервер с brotli, как будет на uPress), 3 прогона:**

| Страница | Performance | Accessibility | Best Practices | SEO | LCP | CLS | TBT |
|---|---|---|---|---|---|---|---|
| index.html | **97–99** | 100 | 100 | 63* | 2.0–2.3 с | 0 | 60–140 мс |
| program-main-home.html | **99** | 100 | 100 | 63* | 1.8–2.0 с | 0 | 70–90 мс |

\* SEO 63 — только из-за `noindex`: прототип намеренно закрыт от индексации. Без сжатия (простой `http.server`) главная даёт 87–96 при LCP 2.7–3.6 с: на хостинге сжатие обязательно.

**Найдено и исправлено при проверке v2:**

| Проблема | Причина | Исправление |
|---|---|---|
| Появления ниже «дня» срабатывали на ~3 экрана раньше | Триггеры пересчитывались в порядке создания, а не сверху вниз; закрепления добавляют место выше | `ScrollTrigger.sort()` после создания сцен + `refresh()` |
| Прокрутка 0–3 кадра/с от hero до «дня» (headless без GPU) | Буква ב, увеличенная в 22 раза, оставалась гигантским слоем | Масштаб ×11 (экран заполняется уже при ×9 на всех окнах 1024–2560px), после зума слой скрывается: 40–60 кадров/с |
| Секция «история» вырастала на 1170 px во время прокрутки (сбивала фокус и триггеры; в поле это был бы CLS) | Рамки фото без ширины схлопывались до загрузки ленивых картинок | `inline-size: 100%` у рамок с `aspect-ratio` |
| LCP: перерисовка главного элемента 1.6 с | В анимации буквы был `background-position` (не композитор) | Только opacity/transform |
| Моменты «дня» 2–5 недоступны скринридеру | `autoAlpha` ставил `visibility: hidden` | Только `opacity` |
| Видимый текст логотипа не входил в доступное имя (2.5.3) | `aria-label` + `aria-hidden` у знака | Видимый текст + `nh-sr-only` «— לדף הבית» |
| Мелкие тексты формы на фиолетовом фоне 1.1:1 | Селектор `.v2-cta p` перекрашивал текст внутри белой формы | Селектор сужен до текста секции |
| Цифры в надзаголовках 4.4:1 | `opacity: .9` | Убрана |
| Мобильная панель вне landmark | `<div>` после подвала | `<aside aria-label="תיאום ביקור מהיר">` |
| Кнопка «הפחתת תנועה» не гасила переходы между страницами | `@view-transition` зависел только от системной настройки | Анимации переходов отключаются и классом `nh-reduce-motion` |

**Не проверено здесь** (будет на шаге 5):
- реальные Safari (macOS/iOS), Firefox, Android Chrome — в среде есть только Chromium; «iPhone 13» — эмуляция в Chromium;
- плавность сцен на реальных устройствах с GPU (в этой среде компоновка программная, без GPU);
- реальные скринридеры (NVDA, VoiceOver);
- Lighthouse на настоящем WordPress-сайте.
