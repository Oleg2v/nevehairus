# Прототип — v3.1 «אותיות שגרים בהן» (шаг 2)

Живой прототип главной и одной внутренней страницы (HTML, CSS, немного JS) плюс страница дизайн-системы. Иврит, RTL, WCAG 2.2 AA (ת"י 5568), режимы «בשפה פשוטה», «מצב רגוע» и «הפחתת תנועה».

> **История версий.**
> - v1 «בית לחיים» — тёплый редакционный шаблон, высмеян заказчиком (наши критики: 5.3–5.6 по шкале Awwwards).
> - v2 «ב׳ — בית» — вход в дом через букву на тёмном фоне. Жюри сочло часть приёмов штампами.
> - **v3 «אותיות שגרים בהן»** — выбор трёх судей, среднее 7.71 ([research/06](../research/06-jury-v2-to-v3.md)).
> - **v3.1** — v3 после второго раунда жюри: четыре судьи оценили собранный сайт в 6.9–7.4 и дали конкретный список правок. Всё, что они нашли, исправлено; см. [ниже](#что-изменилось-после-второго-раунда-жюри-v31).
>
> Кадры и анимации: [STORYBOARD.md](STORYBOARD.md). Живая копия v2 — [`v2/`](v2/), кадры v2 и v1 — [`storyboard/v2/`](storyboard/v2/), [`storyboard/v1/`](storyboard/v1/).

## Как открыть

Нужен любой статический сервер: шрифты и модули по `file://` браузер не загрузит.

```bash
cd prototype
```

```bash
python3 -m http.server 8080
```

Затем открыть http://localhost:8080/. Простой язык: кнопка «בשפה פשוטה» в шапке или ссылка `index.html?plain=1`. Спокойный режим и «הפחתת תנועה» — в панели «תצוגה» (на телефоне — в меню) или системная настройка *Reduce motion*.

│   ├── js/v3.js                   ← v3: простой язык и спокойный режим, панель «תצוגה», колонтитул, вес ב при прокрутке, дверь, блик, работы в ладони

├── v2/                            ← замороженная живая копия v2 (свои CSS/JS, общие шрифты и фото)

└── DESIGN-SYSTEM.md               ← принципы, токены, контраст (44 пары), шкалы, компоненты, перенос в Elementor

Сборка (Python 3, без зависимостей):

```bash
python3 -I scripts/build_prototype_html.py
```

Скрипт собирает `src/*.html` → `*.html`. Он склеивает и минифицирует CSS и подставляет:
- адаптивные `<picture>` из `assets/img/manifest.json`;
- буквы: `{{letter …}}`, `{{letterroom …}}`, `{{letterdata …}}`.

Контуры букв и фото v3 пересобираются так (нужны fontTools и Pillow; шрифт — оригинал Frank Ruhl Libre из google/fonts, фото — оригиналы с текущего сайта):

```bash
python3 -I scripts/build_letters.py "FrankRuhlLibre[wght].ttf" prototype/assets/letters.json
```

```bash
python3 -I scripts/build_prototype_images.py --src <папка_оригиналов> --out prototype/assets/img --v3
```

## Что в прототипе временное

- **Фото** взяты с текущего сайта. На них нет узнаваемых лиц: люди со спины, интерьеры, работы жильцов. Перед запуском их заменит съёмка с оформленными согласиями ([бриф](../research/03-creative-directions.md#бриф-на-фотосъёмку-нужна-до-запуска)). Для третьего дома снимков нет, поэтому в его «комнате» спокойное небо.
- **Работы жильцов** (горшки, совы, мандала) показаны с кредитом «עבודת יד של דיירות ודיירי נווה האירוס». Перед запуском нужно согласие авторов на публикацию и на форму кредита (группа или инициалы). Мандалу без согласия авторов не режем и не вращаем: она показана целиком, вписанной в ס. **Нижний ряд плиток обрезан уже на исходном снимке** — нужна новая фотография работы целиком.
- **Логотип** временно заменён типографским знаком. Нужна векторная перерисовка ириса, согласованная с заказчиком.
- **Цитаты мамы жильца** — дословно из её письма на странице отзывов, без фамилии. На главной теперь строка о жизни («הבן שלי וחבריו מבלים מחוץ לכותלי המוסד מדי שבוע» — часть предложения, без связки «ולמעשה»), строка о медицинской и социальной команде перенесена на страницу дома. Перед запуском нужно заново получить согласие. **Не проверено:** в письме имя написано двумя способами — «לילה» в начале и «ליליה» в подписи; в прототипе — «ליליה», как в подписи.
- **Голос самих жильцов.** Сейчас на страницах говорят родители и учреждение. Когда будут оформленные согласия, нужен разворот с короткими словами жильцов (с поддержкой команды и специалиста по простому языку).
- **Тексты «בשפה פשוטה»** — черновик для специалиста по פישוט לשוני и для проверки с жильцами. Теперь у всех заголовков, цифр, историй, согласий, баннера cookies и видео есть простой вариант; кнопка честно говорит «החלקים החשובים בדף כתובים עכשיו בשפה פשוטה». Короткие подписи (названия домов, поля формы, глаголы дня) остаются как есть.
- **Формы ничего не отправляют.** В WordPress отправка пойдёт через `wp_mail()` (шаг 3). Уведомление о приватности одно на обе формы ([`src/partials/privacy-note.html`](src/partials/privacy-note.html)) — черновик для юриста. В поле «מי ממלא את הטופס?» первый вариант — «אני, בשביל עצמי»; есть «תומך או תומכת בקבלת החלטות» (поддержка в принятии решений вместо опекунства — поправка 18 к חוק הכשרות המשפטית והאפוטרופסות, 2016; [материалы משרד המשפטים](https://www.gov.il/BlobFolder/reports/jurist_attorney_course/ar/sitedocs_amendment_18_alternatives.pdf), [ביטחון סוציאלי 124](https://btl.gov.il/Publications/Social_Security/124/Documents/rimon80.pdf)).
- **Кредит агентства** в подвале пока текстом: «עיצוב ופיתוח: קורנגה» со ссылкой на koranga.co.il. Когда агентство даст логотип (лучше SVG), он встанет на это место. Их знак — белая надпись и оранжевый значок, рассчитан на тёмный фон, а наш подвал тёмный.
- Ссылки на ещё не сделанные страницы ведут на якоря главной.

## Что изменилось после второго раунда жюри (v3.1)

Четыре независимых судьи посмотрели собранную v3 (скриншоты, замеры, трассировки) и выставили оценки по шкале Awwwards: Awwwards-арт-директор ≈ 7.0, доступность и достоинство ≈ 7.1, иврит ≈ 7.15, техника и движение ≈ 7.1 ([research/06](../research/06-jury-v2-to-v3.md#6-раунд-2-жюри-смотрит-v3)). Порог «сайта дня» — 7.2–7.6. Ниже — что они нашли и что сделано.

| Что нашли судьи | Что сделано |
|---|---|
| Утончение ב происходило, пока буква уезжала с экрана | Обложка 150svh, ב и текст закреплены CSS sticky (≥ 1024×700, только когда есть движение); весь переход 800→300 идёт на экране, в конце видны шаги людей по дорожке |
| Мандала жильцов была обрезана, блик выходил за букву | Новый квадратный кадр работы целиком (`v3-mandala`), вписан в эллипс по контуру ס (режим сборки `fit="whole"`); кольца сняты с колец самой работы; блик только по стеклянному центру и внутри того же контура |
| Форма визита — отдельная карточка, дверь «не открывается» в неё | Широкая ד на весь разворот (как буквы, которые растягивает писец): голова у правого края, флажок у левого, нога до «пола»; форма стоит в проёме, без тени; перемычка один раз дотягивается от 60% до 100% |
| Видео-фасад: постер занимал 58% рамки | Квадратный «отпечаток», постер на всю рамку и не затемнён, квадратная кнопка, подпись под фото |
| Колонтитул ломал шапку на 1366–1450 px; шапка в две строки | Колонтитул под словесным знаком, вне строки; точки перелома в em (крупный шрифт браузера → компактная шапка); номер телефона в шапке с 90em. Шапка 72 px в одну строку на 1120–2560 px |
| Метки «כ׳ ס׳ ל׳ ד׳» и «ב׳ · בית» читались как букварь; идея букв нигде не сказана | Метки и префиксы убраны. Имя буквы звучит в заголовке её разворота («בית», «בכף היד», «לסמוך», «ללמוד», «הדלת») и один раз прозой в колофоне |
| Все развороты одного ритма (буква справа, линейка, H2, серый лид) | כ без линейки, основание срезано краем разворота; ס в центре, слова и круги по сторонам; «1957» плакатного размера открывает годы; голоса открывает цитата (H2 только для скринридера); ל у дальнего края пересекает линейку |
| «Полароиды» с белым полем и тенью | «Отпечатки»: прямой срез, линия 1 px, нумерованные подписи; галерея начинается с обеденного стола |
| Простой режим ломал обложку; на телефоне кнопка визита ниже первого экрана | Простой режим: маленькая ב рядом с текстом, кнопка под ним. Телефон: ב рядом с H1, фраза и кнопка на первом экране; панель визита появляется, когда кнопка обложки ушла |
| Простой язык покрывал меньшую часть страницы, а кнопка обещала «весь דף» | Простые варианты у всех заголовков, цифр, историй, согласий, cookies и видео; честная фраза «החלקים החשובים בדף כתובים עכשיו בשפה פשוטה» |
| Форма не давала выбрать «я сам/сама» | «מי ממלא את הטופס?»: «אני, בשביל עצמי» первым, «תומך או תומכת בקבלת החלטות»; одинаковые тексты обеих форм, общее уведомление о приватности, человеческие сообщения об ошибках |
| Баннер cookies при увеличении 200–400% был выше экрана | Не выше экрана, прокручивается внутри; на коротких экранах объяснение свёрнуто в «מה זה אומר?»; отступ прокрутки под баннер считается по его реальной высоте |
| Тексты: опечатка «בקן», «הפרעות נפשיות», «קפסולות», кальки, косые черты в простом режиме, цитата о медицине на главной | Исправлено по списку судьи; на главной цитата мамы о жизни («הבן שלי וחבריו…»), цитата о команде — на странице дома; в простом режиме косвенная речь |
| Мелочи доступности | Объявления из меню (своя live-область в `<dialog>`), фокус после cookies на `<main>`, кнопка в блоке простого языка без `aria-pressed` и без прыжка фокуса, рамки кнопок шапки в forced colors, короткие экраны без фиксированной шапки и панели |
| Отрицательный трекинг на иврите | 0 у всех заголовков на иврите; −0.03em только у цифр |
| Переход «индекс домов → страница дома» заканчивался тем, что шторка заново стирала букву; при отключённой анимации шторка закрывала обложку навсегда | Шторка по умолчанию уже убрана (анимация только «от»), при входе через переход (`pagereveal`) не играет; имя перехода ставится скриптом только для этого пути; у баннера cookies своё имя перехода |
| Ссылки с якорями с другой страницы прокручивали всю главную за 1.5 с | Плавная прокрутка только для ссылок внутри страницы (`html:focus-within`); с другой страницы — сразу на место |
| На ретине между фото и буквой — светлая щель 1 px | «Комната» заходит под буквы на 4 единицы шрифта со всех закрытых сторон; проверено при DPR 2: 0 щелей |
| На телефоне ב продолжала худеть, когда «комната» уже ушла с экрана | Без закрепления переход заканчивается, пока «комната» видна минимум на ~80% |
| На 2560×1440 и планшете в портрете первый экран наполовину пуст | Буква растёт до 62rem, заголовок — до min(14rem, 12vh), контейнер с 1800 px — 110rem; на портретном планшете буква в широкой колонке |
| Перенос в Elementor сломал бы колонтитул и «место чтения» | Скрипты ищут развороты по `[data-running]`, а не по структуре DOM; заметки для шага 3 — в [plugin/README](../plugin/README.md) |
| Дверь могла остаться закрытой без JS; полоса двора в галерее растянута из маленького файла; половина CSS — неиспользуемый v1; фиксированный слой «бумажного зерна» поверх всего | Дверь закрывается только когда `v3.js` загружен; шестое фото галереи — обычная клетка; компоненты v1 вынесены в `legacy-v1.css` вне сборки (страницы совпали пиксель в пиксель); слой зерна в v3 выключен |

Сознательно **не** сделано: маска-градиент на открытой стороне ב и כ (край фото совпадает с концами линий буквы, срез читается как часть архитектуры); перекраска фона за работами жильцов (это вмешательство в снимки их работ).

## Проверки v3.1

Проведены 15.11.2026 в этой среде: Chromium 1243 через Playwright, Lighthouse 12.8.2, axe-core 4.14.0.

**Доступность (axe-core):** теги wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa, best-practice.

| Что проверено | Нарушений |
|---|---|
| Главная и страница дома × (десктоп, iPhone 13, reduced motion) × (обычный режим, `?plain=1`) | **0** |
| Состояния: баннер cookies с настройками, согласие на видео, форма со сводкой ошибок, панель «תצוגה», спокойный режим, лайтбокс, мобильное меню, мобильная панель визита | **0** |

**Клавиатура (Tab по всей странице):** 339 остановок (две страницы; десктоп, iPhone, reduced motion), **0 проблем**. У каждой остановки видимое кольцо фокуса, ни одна не перекрыта шапкой, панелью или баннером (`elementFromPoint`).

**Ширина и масштаб:**
- нет горизонтальной прокрутки на 320, 360, 768, 1024, 1120, 1200, 1280, 1366, 1920 и 2560 px (главная, страница дома, дизайн-система, простой режим);
- шапка 72 px в одну строку на всех ширинах от 1120 до 2560 px; при шрифте браузера 20 и 24 px на 1366 px — компактная шапка с меню, ничего не уходит за экран;
- WCAG 1.4.12 (интервалы текста): ничего не обрезано, шапка переносится, но все кнопки на экране;
- баннер cookies на 400% (320×256) и 200% (720×450, 683×384): не выше экрана, прокручивается внутри, фокус на экране;
- forced colors: буквы и рамка двери видны, у кнопок шапки есть границы.

**Lighthouse (мобильный профиль: медленный 4G, 4× CPU; локальный сервер с brotli, как будет на uPress), 3 прогона:**

| Страница | Performance | Accessibility | Best Practices | SEO | LCP | CLS | TBT |
|---|---|---|---|---|---|---|---|
| index.html | **99** | 100 | 100 | 63* | 2.0 с | 0 | 0–20 мс |
| program-main-home.html | **99–100** | 100 | 100 | 63* | 1.5–1.8 с | 0 | 0 мс |

\* SEO 63 — только из-за `noindex`: прототип намеренно закрыт от индексации. Страницы запрашивались по прямому адресу, без редиректа `.html` → `/`.

При первом прогоне v3.1 главная дала TBT 130–190 мс: новый код панели визита и баннера читал вёрстку во время загрузки. Теперь это делают `IntersectionObserver` и `ResizeObserver`, а первый замер обложки — в кадре прокрутки.

**Не проверено здесь** (будет на шаге 5):
- реальные Safari (macOS/iOS), Firefox и Android Chrome — в среде есть только Chromium; «iPhone 13» — эмуляция в Chromium (перемычке двери нужен `@property`; где его нет, дверь просто сразу открыта — поддержку в Safari и Firefox здесь не проверяли);
- плавность морфинга ב на реальных телефонах;
- реальные скринридеры (NVDA, VoiceOver);

### Найдено и исправлено при проверке v3 (первый раунд)

| Проблема | Причина | Исправление |
|---|---|---|
| На телефоне LCP-фото скачивалось дважды (480 и 1080 px), LCP 3.0 с | `<meta viewport>` стоял после `<title>` и preload, и сканер предзагрузки Chrome считал `sizes` от ширины 980 px | `head` подключается сразу после `charset`: одна загрузка 37 КБ, LCP 2.0 с |
| В режиме простого языка ломалась шапка | Класс режима `nh-plain` совпал с классом компонента v1 `.nh-plain` | Режим называется `nh-plainmode` |
| Горизонтальная прокрутка на 320–360 px | Кнопки шапки не помещались; длинные подписи кнопок и описания строк не переносились | Узкая шапка без телефона (он в меню и в панели визита), перенос в кнопках и строках |
| Финальная ם в «שמיים» выпадала из слова | Блок «комнаты» стоял внутри `<p>` — парсер закрывал абзац | Обёртка `div` |
| Тессера-точка висела ниже строки | Не учтён спуск шрифта | Положение по метрикам Frank Ruhl Libre (спуск 0.334em) |
| Край облака в «комнате» был похож на лицо в профиль | Неудачный фрагмент потолка | Новый кадр неба, `v3-sky-room` |
