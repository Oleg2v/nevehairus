# Дочерняя тема `hello-elementor-child`

Дочерняя тема для [Hello Elementor](https://wordpress.org/themes/hello-elementor/) (проверено на 3.5.2 и Elementor 4.4.0).

С v3.2 тема держит то, что действует на весь сайт, — чтобы оно оставалось и при выключенном плагине `nevehairus-site` (плагин теперь стилизует только свои виджеты): [research/07-calm-v3.2.md](../research/07-calm-v3.2.md) §12.5.

- **`functions.php`**: выключает reset.css и theme.css темы Hello, её ссылку пропуска и заголовок страницы на страницах из Elementor (только на самой записи: на поиске и в архивах H1 остаётся), Google Fonts Elementor; печатает ссылку пропуска «דילוג לתוכן הראשי» на `wp_body_open` @5; оборачивает содержимое шаблонов Elementor «Full Width» и «Canvas» в `<main id="content" class="site-main" tabindex="-1">` (шаблоны Hello уже дают `main#content`); подключает `style.css` после `elementor-frontend`; разделитель заголовка страницы «|», как в прототипе; выключает кэш элементов Elementor на сайте, пока плагин `nevehairus-site` не может зарегистрировать виджеты (выключен, пропущен аварийным выключателем или не может работать): в этом кэше лежит готовый HTML статичных виджетов плагина, и без плагина он печатался бы без стилей, а страница, отрисованная без плагина, попала бы в кэш для всех (1.1.2).
- **`style.css`**: `box-sizing`, `body` (фон бумаги, цвет, шрифт с системными запасными, `overflow-x: clip`), `:root { scroll-behavior: auto }` (переход к якорю мгновенный: Elementor 4.4.0 включает плавную прокрутку на всём сайте, 1.1.2), кольцо фокуса, подчёркивание ссылок, стили ссылки пропуска, контейнер страниц не из Elementor, формы WordPress на шаблонах Hello (комментарии, поиск, пароль: поля 56 px, рамка 2 px, 1.1.2), ссылки и списки подвала Theme Builder (подвал собран из штатных виджетов Elementor, §12.6: списки без маркеров, строка-ссылка не ниже 44 px, на телефоне две колонки ссылок — класс `nh-footer-links`; у абзацев Text Editor нет браузерных полей по краям, «קולופון.» цветом бумаги, кредит агентства жирный — класс `nh-footer-credit`, 1.1.2), системный `prefers-reduced-motion`. **1.1.3:** сетка подвала по точкам прототипа (две колонки с 40em, `5fr 3fr 4fr` с 64em), строки контактов одной высоты 44 px, последняя нечётная ссылка «(PDF)» на всю строку, `text-wrap: pretty` у абзацев подвала (без висячих слов). **1.1.4:** у ссылок внутри строки подвала (телефон после «טלפון:», кредит после «עיצוב ופיתוח:») рамка фокуса 2 px вплотную к словам — не наезжает на двоеточие.

Ставить **вместе** с плагином (сейчас 0.2.3): иначе на время вернётся CSS Hello, а ссылки пропуска окажется две или ни одной.

На тестовый сайт её ставит `python3 -I scripts/test_site.py setup`: собирает zip из этой папки, устанавливает Hello Elementor из каталога wordpress.org (если её нет) и активирует дочернюю тему. `setup` не трогает уже установленную дочернюю тему: обновлённую ставит `python3 -I scripts/test_site.py theme --go` (с откатом на Hello Elementor, если сайт сломается).
