## Общие правила движения

| Правило | Как реализовано |
|---|---|
| Движение помогает читать, а не мешает | Только opacity/transform (на композиторе). Никакого scroll-jacking и сторонних smooth-scroll библиотек: прокрутка всегда нативная |
| Нет бесконечных циклов | Анимации по времени есть только у входа в hero (≤ 2.2 с). Всё остальное привязано к скроллу пользователя, поэтому WCAG 2.2.2 соблюдается |
| Два способа выключить | 1) системная настройка `prefers-reduced-motion: reduce`; 2) кнопка **«הפחתת תנועה באתר»** в подвале и мобильном меню (`aria-pressed`, запоминается в localStorage) |
| Reduced motion — не «сломанная» версия | Весь контент виден сразу, GSAP **вообще не загружается**, CSS-анимации сжимаются до конечного состояния, смена картинок мгновенная, плавная прокрутка и View Transitions выключены |
| Производительность | Вход в hero сделан на CSS (не ждёт JS, не тормозит LCP). GSAP + ScrollTrigger (локально, без CDN) грузятся **после `load`**. Скрываются только элементы ниже первого экрана, и есть страховка 3.5 с, после которой контент показывается в любом случае |
| Токены | `--nh-dur-1` 160ms · `--nh-dur-2` 320ms · `--nh-dur-3` 800ms · `--nh-dur-4` 1200ms; `--nh-ease-out` = cubic-bezier(.22,1,.36,1) ≈ power3.out; `--nh-ease-in-out` = cubic-bezier(.65,0,.35,1) ≈ power2.inOut |

Код: вход в hero — [`assets/css/main.css`](assets/css/main.css) (раздел Hero), скролл-эффекты — [`assets/js/motion.js`](assets/js/motion.js), смена кадров истории и UI — [`assets/js/site.js`](assets/js/site.js).

### S1 · Hero — «בית. לחיים.»
| Десктоп | Мобильный |
|---|---|
| ![](home-desktop-01-hero.jpg) | ![](home-mobile-01-hero.jpg) |

**Сообщение за 10 секунд.** Это дом (а не больница) для людей с מוגבלות שכלית התפתחותית в Нес-Ционе, с 1957 года, под надзором министерства. Можно прийти познакомиться.

**Контент:**
- надзаголовок «מעון נווה האירוס · נס ציונה»;
- H1 «בית. / לחיים.»;
- лид;
- CTA «בואו להכיר — תיאום ביקור» и телефон;
- ряд доверия: «בפיקוח משרד הרווחה», «מעל 100 דיירים ודיירות», ссылка «לקריאה בשפה פשוטה»;
- фото в арке (двое идут в обнимку, со спины), штамп «מאז 1957», подпись «צעד צעד, ביחד.».

**Анимации:**

| Элемент | Триггер | Длительность / задержка | Easing | Мобильный | Reduced motion |
|---|---|---|---|---|---|
| Надзаголовок, лид, CTA, ряд доверия (`.nh-rise`) | Загрузка страницы (CSS) | 1.2 с; задержка 80 мс + 110 мс × индекс | `--nh-ease-out` | То же | Конечное состояние сразу |
| Строки H1 (`.nh-line > span`) | Загрузка (CSS) | 1.1 с; 60 мс + 130 мс × строка | `--nh-ease-out`, translateY 105% → 0 внутри `overflow: clip` | То же | Сразу |
| Арка фото | Загрузка (CSS) | 1.5 с, задержка 120 мс | `--nh-ease-in-out`, `clip-path: inset(14% 10% 0 10% round …)` → `inset(0)` | То же | Сразу |
| Фото в арке «оседает» | Загрузка (CSS) | 2.2 с | `--nh-ease-out`, scale 1.12 → 1 | То же | Сразу |
| Рукописная линия под «לחיים» | Загрузка (CSS) | 1.1 с, задержка 900 мс | `--nh-ease-in-out`, stroke-dashoffset 1 → 0 | То же | Линия видна сразу |
| Штамп «מאז 1957» | Загрузка (CSS) | 0.9 с, задержка 900 мс | `--nh-ease-out`, scale .6 + rotate −20° → 1/0° | То же | Сразу |
| Пунктирное кольцо штампа | Скролл hero (top→bottom) | scrub 0.6 | linear, rotate 0 → 160° | То же | Статично |
| Параллакс фото | Скролл hero | scrub | linear, yPercent 0 → 6 (обёртка `.nh-parallax`) | **Выключен** (< 1024px) | Выключен |

### S2 · Манифест «מה מנחה אותנו»
| Десктоп | Мобильный |
|---|---|
| ![](home-desktop-02-statement.jpg) | ![](home-mobile-02-statement.jpg) |

«אנחנו מאמינים שלכל אדם מגיע בית: מקום שמכבד את מי שהוא, שמח בכל הצלחה קטנה, ומתקדם איתו צעד צעד.»

| Элемент | Триггер | Длительность | Easing | Мобильный | Reduced motion |
|---|---|---|---|---|---|
| Слова «прочитываются» (opacity **0.55** → 1) | ScrollTrigger: `top 82%` → `bottom 52%` | scrub 0.6, stagger 0.1 | linear | То же | Текст сразу 100% |
| Надзаголовок, ссылка | Вход в зону (`top 88%`, once) | 0.8 с, stagger 0.09 | power3.out, y 28 → 0 | То же | Сразу |

Доступность. Минимум 0.55 подобран так, чтобы ещё не «прочитанные» слова держали **3.54:1**, то есть AA для крупного текста. Для скринридера целое предложение лежит в скрытой копии (`nh-sr-only`), а разбитые на слова span'ы помечены `aria-hidden`.

**Лайтбокс:**
- `<dialog>`: фокус уходит на «סגירה», Esc закрывает, фокус возвращается на миниатюру;
- в RTL **← = следующая**, → = предыдущая, Home и End;
- живой регион объявляет «תמונה 2 מתוך 6. <alt>».

**Форма:**
- ошибки только при отправке: сводка со ссылками на поля, `aria-invalid`, `aria-describedby`;
- ошибки снимаются по мере исправления, без проверки на blur, чтобы вёрстка не прыгала под курсором;
- honeypot, согласие, уведомление по §11 (черновик для юриста).

## Переходы между страницами

`@view-transition { navigation: auto; }` — только при `prefers-reduced-motion: no-preference`. Браузерный кроссфейд около 250 мс в Chromium 126+ и Safari 18.2+, остальные просто переходят без него.
