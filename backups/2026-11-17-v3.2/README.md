- В копиях те же данные Elementor, что в оригиналах: при снятии проверено, совпадают байт в байт.
- Условия показа шапки и подвала в копиях не включены, чтобы копия никогда не подменила рабочий шаблон. Они сохранены отдельно, в поле `_nh_backup_conditions`.
- Ещё на сайте две записи настроек, которые нигде не применяются:
  - `nh_backup_v32_kit` — глобальные цвета и шрифты Elementor (Kit #4);
  - `nh_backup_v32_options` — главная страница сайта (#32), условия Theme Builder, меню, название сайта.

**В репозитории** — [site-state.json](site-state.json): те же данные в JSON (документы, Kit, настройки, версии).

**Версии на момент бэкапа:**
- WordPress 7.1.4;

- плагин `nevehairus-site` 0.2.6;
- тема `hello-elementor-child` 1.1.5.

Код этой версии — коммит `f3ba653` в ветке `claude/upbeat-fermi-3acsyh`.

## Как вернуть

1. **Быстро (главная).** Скрипт выкатки v4 откатывает главную одной командой: `python3 -I scripts/test_site.py v4 --rollback`.
   - Он копирует данные из #58 обратно в #32; адрес и статус главной не меняются.
   - Шапку и подвал v4 он переводит в черновики, и снова работают #34 и #35.
2. **Вручную в Elementor**, если скрипта нет под рукой:
   1. «Шаблоны → Theme Builder»: шапку и подвал v4 перевести в черновики.
   2. Открыть черновик #58 в Elementor, в «Навигаторе» выделить всё и скопировать.
   3. Открыть #32 в Elementor, удалить содержимое, вставить и нажать «עדכון».
3. **Целиком из кода.** Взять коммит `f3ba653` и выполнить по очереди:
   ```bash
   python3 -I scripts/test_site.py deploy --go
   ```
   ```bash
   python3 -I scripts/test_site.py theme --go
   ```
   ```bash
   python3 -I scripts/test_site.py pages --go
   ```
   Это пересоберёт плагин 0.2.6, тему 1.1.5, обе страницы, шапку и подвал v3.2.
4. **Весь сайт.** Ежедневные бэкапы uPress за 30 дней. Восстанавливает Олег в панели uPress; мы панель не трогаем.
