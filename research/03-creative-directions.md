# Три креативных направления и рекомендация

> Шаг 1г. Принципы взяты из бенчмарка ([01](01-benchmark-awards.md)): номера в скобках вида (#7) — сайты из его сводной таблицы. Дизайн не копируем, переносим принципы. Шрифты проверены по метаданным Google Fonts (`fonts.google.com/metadata/fonts`, 15.11.2026). Лицензии по ссылкам ниже открываются (HTTP 200). Коммерческие гарнитуры описаны по [05, раздел 6](05-compliance-a11y-privacy-licenses.md#6-шрифты-коммерческие-ивритские-гарнитуры-израильских-словолитен). Контраст посчитан по формуле WCAG ([`scripts/contrast.py`](../scripts/contrast.py)).

Общие для всех трёх направлений требования: RTL, AA-контраст, клавиатура, `prefers-reduced-motion`, шрифты хостятся у нас (без Google CDN), без автозапуска видео, без scroll-jacking.

## A. «בית לחיים» — тёплая редакционная история (✅ рекомендуем)

**Настроение.** Хорошо изданная книга о доме. Тёплая бумага, терракота, оливковый лист, кружевная скатерть, послеполуденный свет в саду. Фиолетовый ирис из логотипа — главный акцент. Мозаика, которую делают жильцы, — живая деталь.

**Идея.** «בית. לחיים.»: дом на всю жизнь и тост «за жизнь». Подпись бренда — «צעד צעד, ביחד», фраза с текущего сайта.

**Палитра** (все текстовые пары проходят AA; полная таблица — [DESIGN-SYSTEM.md](../prototype/DESIGN-SYSTEM.md)):

|---|---|---|---|
| paper | `#F7F1E7` | фон | — |
| ink | `#1F2421` | текст | 14.03:1 на paper |
| iris-700 | `#4A2D84` | бренд, кнопки, ссылки (из логотипа) | 9.35:1; белый на нём — 10.5:1 |

**Шрифты (иврит)**
- Заголовки — **Frank Ruhl Libre**, вариативный 300–900. Автор Yanek Iontef, на основе классического Frank-Rühl 1908 г. Лицензия **SIL OFL 1.1**: [Google Fonts](https://fonts.google.com/specimen/Frank+Ruhl+Libre) · [OFL.txt](https://github.com/google/fonts/blob/main/ofl/frankruhllibre/OFL.txt).
- Текст и интерфейс — **Assistant**, вариативный 200–800. Иврит — Ben Nathan, латиница — Adobe. Лицензия **SIL OFL 1.1**: [Google Fonts](https://fonts.google.com/specimen/Assistant) · [OFL.txt](https://github.com/google/fonts/blob/main/ofl/assistant/OFL.txt).
- Премиальный апгрейд, если клиент готов купить лицензию на свой домен:
  - **פרנק־רי (Frank-Re) + פלוני (Ploni)**, AlefAlefAlef — одна словолитня, одна лицензия;
  - **Canela HLAR + Lyon HLAR** (Fontef).
  Модели лицензий — [05, раздел 6.3](05-compliance-a11y-privacy-licenses.md#63-модели-веб-лицензий).

**Фирменные элементы:**
- фото в **арке-окне** («дом», «укрытие»);
- желтый **маркер** под ключевыми словами;
- **рукописная линия** под «לחיים»;
- **мозаичные плитки** в цветах работ жильцов;
- крупные годы шрифтом с засечками;
- блоки «בשפה פשוטה».

**Язык анимации — «дыхание»:**
- спокойные появления: 0.8 с, power3.out, сдвиг на 28 px;
- раскрытие арки: 1.5 с, power2.inOut;
- «чтение» манифеста по словам со скроллом;
- медленный параллакс не больше 6%;
- мозаика собирается один раз.

Без scroll-jacking, без бесконечных циклов. У каждого эффекта есть вариант для reduced motion. Подробная спецификация — [STORYBOARD.md](../prototype/STORYBOARD.md).

**Подача фото:**
- естественный свет, уровень глаз;
- люди со спины, руки за работой, пространства;
- портреты — только с оформленным согласием;
- единая тёплая цветокоррекция;
- без стоков, без «больничных» крупных планов, без кадров «жалости».

**Опоры из бенчмарка:**
- (#7) Elders Project — истории людей с достоинством;
- (#10) Units — жильё как сообщество;
- (#13) Anotherkind — архитектура «life-led»;
- (#4) TLC Healthcare — сфера ухода без больничной эстетики;
- (#9) Woonpact — ясная подача жилищной программы.

**Риски:** направление зависит от качества фото, нужна съёмка (ниже). Шрифт с засечками может выглядеть «старым», поэтому компенсируем современной сеткой.

## B. «פסיפס» — сделано вместе

**Настроение.** Мастерская мозаики: цветные плитки, радость делать руками, сообщество. Сайт как мозаика: каждая программа — своя «плитка» своего цвета.

**Палитра:**

| Токен | HEX | Контраст на `#FBF8F2` |
|---|---|---|
| ink | `#1B1B1F` | 16.2:1 |
| cobalt | `#2348A0` | 7.91:1; белый на нём — 8.38:1 |
| terracotta | `#C4572E` | 4.17:1 ❌ для текста; текстовый вариант `#A3431F` — 5.86:1 |
| teal | `#2A7F7A` | 4.49:1 ❌; текстовый вариант `#1F6560` — 6.41:1 |
| sun | `#F2B33D` | только фон/декор; ink на нём — 9.23:1 |

**Шрифты:**
- **Rubik**, вариативный 300–900 плюс курсив. Hubert & Fischer, иврит — Meir Sadan и др. **OFL**: [Google Fonts](https://fonts.google.com/specimen/Rubik) · [OFL.txt](https://github.com/google/fonts/blob/main/ofl/rubik/OFL.txt). Скруглённая геометрия звучит дружелюбно.
- Для цифр — **Secular One** (Michal Sahar, **OFL**): [Google Fonts](https://fonts.google.com/specimen/Secular+One) · [OFL.txt](https://github.com/google/fonts/blob/main/ofl/secularone/OFL.txt).

**Анимация:**
- изображения и карточки «собираются из плиток»: stagger from random, 0.5 с, power2.out;
- цветовые «заливки» при переходе между программами;
- лёгкий наклон карточек при наведении (±1.5°).
- Reduced motion: всё статично.

**Фото:** крупные планы рук и работ на однотонном цветном фоне; групповые занятия (только с согласием).

**Опоры:**
- (#12) Colonia Zacamil — муралы и участие жителей;
- (#3) SOSOSO — инклюзивный арт-проект;
- (#1) Ahadi Foundation — смелая и достойная подача фонда;
- (#11) One Shared House 2030 — игривое co-living.

**Риски:**
- легко скатиться в «детский сад» для взрослых жильцов;
- насыщенные цвета хуже для сенсорно-чувствительных посетителей (программа по аутизму);
- семьям, которые выбирают уход, это даёт меньше ощущения надёжности;
- труднее держать AA.

## Рекомендация: A «בית לחיים» с двумя заимствованиями

1. **Из B — мозаика как подлинный акцент.** Цвета и плитки взяты из работ самих жильцов, это «их» вклад в бренд. Используется дозированно: разделители, блок «עשוי כאן», карточка CTA.
2. **Из C — «небо» для программы по аутизму.** Страница дается в спокойной палитре sky-200: меньше насыщенности и меньше движения. Это сенсорно-дружелюбный подтон внутри общей системы. Отсылка к реальному потолку «שמיים» нового крыла.

**Почему A:**
- лучше всего попадает в тон «тепло, достоинство, жизнь»;
- для семей это «дом», а не «клиника» и не «детсад»;
- использует подлинные активы клиента: ирис из логотипа, «בית לחיים», «צעד צעד», мозаику жильцов, небесный потолок;
- контраст проверен по всем парам;
- два вариативных OFL-шрифта, ядро которых весит около 46 КБ;
- по Lighthouse прототип даёт 95–99 на мобильном (см. [prototype/README.md](../prototype/README.md#проверки)).

## Бриф на фотосъёмку (нужна до запуска)

- **Формат:** 1–2 дня, фотограф с опытом съёмки людей с инвалидностью. Присутствует сотрудник, которого жильцы знают.
- **Этика:**
  - письменное согласие жильца и/или опекуна на каждый кадр с узнаваемым лицом, с правом отозвать;
  - никаких кадров в уязвимые моменты;
  - лица без согласия — не размывать, а не снимать вовсе (кадрировать: спины, руки).
- **Шот-лист:**
  - пространства: новое крыло, комнаты, сад, двор, виллы в общине — утро и закатный свет;
  - ритм дня: завтрак за общим столом, мастерские (руки, мозаика), кухня, бассейн или верховая езда;
  - персонал за работой (с согласием);
  - семьи в гостях (с согласием);
  - детали: работы жильцов, текстуры, ирисы в саду, если есть;
  - 3–5 портретов с согласием для «голосов».
- **Технические требования:** RAW, длинная сторона от 4000 px. Отдельно вертикали 4:5 для арок и горизонтали 16:9.
