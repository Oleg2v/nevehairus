## 0. Принципы v3.2

1. **Одна большая идея: буквы-архитектура.** ב, כ, ס, ל, ד (и финальная ם) — большие декоративные контуры (`aria-hidden`), их внутреннее пространство — «комната», где живёт фото. Буквы стоят на месте: у каждой один вес навсегда, ничего не морфится, не едет и не закрепляется.
2. **Премиальность даёт типографика:** шкала из 9 ступеней, Frank Ruhl рядом со спокойным Assistant, линейка и сетка, цвет блоками, воздух. Крупный неподвижный шрифт заменяет движение: H1 обложек, глаголы «Дня», «1957». Плюс детали: тессера вместо точки, висящая кавычка, нумерованные подписи «1 ·», подпись «בכף היד». Эффектов нет.
3. **Каждый разворот начинается одинаково:** линейка → H2 → лид, одна мысль на разворот.
4. **Шапка всегда одна и та же:** пять пунктов меню, никаких изменений при прокрутке. «Где я» видно по меню, крошкам и H1.
5. **Текст крупный.** Минимум 16 px, основной текст 18–20 px. Всё кликабельное выглядит кликабельным, контраст AA с запасом.
6. **Фото — небольшие честные «отпечатки» 4:3** в одной обработке. Крупно показываем только работы жильцов. Без фото страница не рассыпается: «комната» показывает небо, «отпечаток» не выводится.
7. **Доступность как дизайн.** «בשפה פשוטה» на всю страницу и «מצב רגוע» — равноправные состояния, а не виджет-оверлей.
8. **Плагин — гость** (для WordPress): его стили и скрипты загружаются только вместе с его виджетами ([research/07 §12](../research/07-calm-v3.2.md)).

**Правила:**
- текст меньше 24px (меньше 18.66px для жирного) — минимум 4.5:1; мелкий текст ink-2 — только ≥ 16 px;
- рамки полей, иконки, кольцо фокуса, дорожки переключателей — минимум 3:1;
- волосные линии декоративны и никогда не единственный признак (строки разделяет и отступ);
- фиолетовый текст логотипа на тёмный фон не ставим (≈ 2:1): в подвале только эмблема и название цветом бумаги;
- `--nh-clay-300`, `--nh-olive-300`, `--nh-sky-500`, `--nh-line` для текста **не используются**.

## 3. Типографика

Заголовки — **Frank Ruhl Libre**, текст и UI — **Assistant**. Оба шрифта под SIL OFL 1.1 и хостятся локально.
- Шрифты разрезаны из оригиналов google/fonts на два файла: **core** — иврит, цифры и пунктуация (~34 КБ + ~12 КБ, с preload); **latin** — латинские буквы, грузится только если на странице есть латиница. `font-display: swap`.
- **Frank Ruhl — только 300, 400, 500.** 300 — только у D-L от 48em (там он ≥ 68 px); D-M и D-S — 400; H3 и название в шапке — 500. Контуры букв — графика, их веса не считаются.
- **Трекинг в иврите 0.** −0.03em только у чисел (`lining-nums`; в «במבט אחד» ещё `tabular-nums`). Курсива нет: выделяем весом и цветом.
- **Минимум 16 px нигде не нарушается**: шапка телефона, подписи, колофон, кнопки, подвал, ошибки.
- **Простой режим не добавляет размеров:** его тексты — `--v3-fs-plain`, H1 обложки — D-M.

| Простой язык | `--v3-fs-plain` | 22 → 24px | Assistant 400, ≤ 36ch | 1.6 | Все тексты `v3-plain`, абзацы обложки в простом режиме, строка «התקשרו:» в меню |

`.v3-dot` — точка заголовка, нарисованная квадратной тессерой (0.12em, на базовой линии по метрикам Frank Ruhl Libre); в DOM остаётся настоящая «.».

Иврит и RTL:
- `lang="he" dir="rtl"`, только логические свойства (`inline-start` = справа);
- телефоны и e-mail обёрнуты в `.nh-ltr` (`display: inline; direction: ltr; unicode-bidi: isolate; white-space: nowrap`) — подчёркивание ссылки доходит до номера;
- «100+» тоже изолируется, иначе в RTL превращается в «+100».

## 4. Сетка, воздух, линии, формы

- **Шкала отступов (база 4px):** `--nh-s-1…10` = 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128.
- **Контейнер** 90rem на всех ширинах (`--nh-max`); боковой отступ `--nh-gutter` = clamp(16px, …, 64px). Горизонтальной прокрутки нет (проверено на 320–2560 px).
- **Отступ разворота** `--v3-pad` = clamp(64px, 2.7rem + 5.333vw, 120px) сверху и снизу. У כ на десктопе нижний отступ переходит на текстовую колонку (основание буквы срезано краем разворота).
- **Ритм разворота:** линейка → 40 px → H2 → 20 px → лид → 48 px → содержимое (`.v3-rule { margin-block-end: 2.5rem }`, `.v3-h2 { margin: 0 0 1.25rem }`, `.v3-lead { margin: 0 0 3rem }`).
- **Три толщины линий:** 1 px ink — линейка и низ шапки; 1.5 px ink — верх списка; 1 px `--v3-hair` — между строками (на тёмном — бумага 30 %).
- **Один радиус — 2 px** (`--nh-r-sm`, `--nh-r-md`, `--nh-r-lg`, `--nh-r-pill` = 2px): кнопки, поля, переключатели, ползунок. У фото радиус 0. Исключение — тессера `.v3-dot`.
- **Теней нет**, кроме рамки «отпечатка» `0 0 0 1px`. Рамки — `border`, не `box-shadow` (Elementor сбрасывает `box-shadow` у ссылок). Полоса блока простого языка — тоже рамка.
- **Шапка** `--v3-mast`: 72 px с 80em, 60 px уже (плюс линия 1 px).
- **Фото: три вида кадра, других нет** — «комната» буквы (пропорцию задаёт буква), «отпечаток» 4:3 (`.v3-print picture { aspect-ratio: 4 / 3 }`, до 21rem, в галерее — во всю клетку), видео 16:9 (до 37.5rem). Файлы уже в нужной пропорции; CSS-ширина × 2 ≤ ширины самого широкого файла (проверка сборки `max=`). У каждого `img` есть `width` и `height`.
- **Формы:** поля `min-block-size: 3.5rem` (56 px), рамка 2 px `--nh-field`, радиус 2 px, текст — ступень «текст»; переход только `border-color .15s`. Подпись — UI 700. Флажки 32 px, нажимается вся подпись. Примечания, подсказки и ошибки — 16 px. Уже 40em кнопка отправки на всю ширину. Ошибки — только после отправки; сводка получает фокус; при уходе из поля ничего не прыгает.

## 6. Переключатели (`.v3-toggle`)

```html
<button type="button" class="v3-toggle" data-calm-toggle aria-pressed="false">
  <span class="v3-toggle__label">מצב רגוע</span>
  <span class="v3-toggle__state" aria-hidden="true" data-on="פועל" data-off="כבוי"></span>
  <i aria-hidden="true"></i>
</button>
```

- Подпись постоянная, состояние — в `aria-pressed` и словом рядом (`::before { content: attr(data-off) }`, при `[aria-pressed="true"]` — `attr(data-on)`), ступень «мелкий» 700.
- Дорожка 44×24 (`2.75rem × 1.5rem`), радиус 2 px; ползунок — квадрат 18 px. **Переходов нет:** ползунок прыгает.
- Цвета: на светлом выкл. — `--nh-field` (6.80:1), вкл. — `--nh-olive-700` (7.08:1), ползунок белый; на тёмном (`.nh-on-dark`) выкл. — `--v3-toggle-dark` (4.92:1), вкл. — `--nh-citrus-400` (9.23:1), ползунок ink.
- Группа: `<div class="v3-switches" role="group" aria-label="הגדרות תצוגה">`. В меню телефона — «בשפה פשוטה» и «מצב רגוע», в подвале — только «מצב רגוע». Переключателя «הפחתת תנועה» больше нет.

## 7. Движение

Полная спецификация — [STORYBOARD.md](STORYBOARD.md#движение-полный-список). Коротко: наведение и фокус (только цвета и прозрачность подложки строки, 150 мс), одно мягкое появление фото «отпечатков» (прозрачность и 8 px, 320 мс, один раз), «+» аккордеона (200 мс). Всё остальное мгновенно. При `prefers-reduced-motion` и в «מצב רגוע» появление выключено.

| Токен | Значение | Использование |
|---|---|---|
| `--nh-dur-1` | 150ms | наведение и фокус: `color`, `background-color`, `border-color`, `text-decoration-color` |
| `--nh-dur-2` | 320ms | единственное появление (фото «отпечатков», один раз) |
| `--nh-ease-out` | `cubic-bezier(.22, 1, .36, 1)` | появление: без перелёта |

`--nh-dur-3`, `--nh-dur-4` и `--nh-ease-in-out` удалены. Сборка прототипа останавливается, если в CSS появятся `@keyframes`, `animation-timeline`, `view-transition`, `@property`, плавная прокрутка или `position: sticky`.

## 9. Перенос в Elementor 4.4 (шаги 3–4)

- **Развороты** (обложка, индекс домов, день, ладонь כ, круги ס, годы, голоса, шаги, ל-вакансии, дверь ד, цифры, галерея, «что есть в доме», истории, «להמשך קריאה») и шапка — **виджеты нашего плагина** (`Widget_Base`), разметка и CSS — по собранному прототипу v3.2. Подвал — из штатных виджетов Elementor плюс виджет `display` для «מצב רגוע» ([research/07 §12.6, §13](../research/07-calm-v3.2.md)).
- «Буква с комнатой» — общий PHP-компонент: контуры из `letters.json`, фото из медиатеки, вес — константа виджета. У каждого виджета есть поле «בשפה פשוטה». Все тексты, фото и ссылки — поля в редакторе.
- **Плагин — гость:** стили и скрипты только на страницах с его виджетами; ничего глобального; без плагина сайт открывается без ошибок ([research/07 §12](../research/07-calm-v3.2.md)).
- Шрифты `Frank Ruhl Libre` и `Assistant` загружены локально, Google Fonts в Elementor выключен (тема). В «Advanced» ни одного Motion Effect и ни одной Entrance Animation.
