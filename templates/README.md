# JSON-шаблоны и глобальные настройки (шаг 4) — ещё не начат

Здесь будут резервные копии всего, что собрано в Elementor (через MCP или вручную). Порядок восстановления: **дизайн-система → шаблоны → страницы**, потому что элементы ссылаются на id классов и переменных ([research/04 §3.5](../research/04-tech-elementor-wp-upress.md)).

Три слоя экспорта после каждой вехи:

1. **Website Template ZIP** — настройки, классы, переменные, Default Styles.
2. **Design System ZIP** — переменные и глобальные классы.
3. **JSON каждого шаблона и страницы** из Template Library.

Секретов в экспортах быть не должно. Перед коммитом проверить, что в них нет Application Password и токенов MCP.
