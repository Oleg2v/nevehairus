### Чек-лист: выполню сразу, как только будет доступ

1. **Бэкап.** Убедиться, что в uPress есть свежая копия (хранятся 30 дней). При необходимости попросить Олега сделать ручную. В панели uPress сами ничего не меняем.
2. **הגדרות → קריאה** → «בקשה ממנועי חיפוש שלא לאנדקס את האתר» ✔.
3. **הגדרות → קישורים קבועים** → «שם הפוסט» (`/%postname%/`).
4. **הגדרות → כללי** → אזור זמן «ירושלים».
5. **Тема — Hello Elementor** (по данным research/04, актуальная версия 3.5.2) **+ дочерняя `hello-theme-child`**; активировать дочернюю. Почему не своя минимальная тема: Hello — официальная «пустая» тема Elementor, весь макет (шапка, подвал, шаблоны) делается в Theme Builder Elementor Pro. Дочерняя тема даёт место для нашего CSS без риска потерять его при обновлении. Своя тема дублировала бы Hello без выигрыша. Hello Biz не берём: по research/04 он скоро перейдёт в режим поддержки.
6. **ezCache → режим разработки** (Dashboard → Development Mode). На тестовом сайте для этого есть REST-маршрут `/wp-json/ezcache/v1/dev-mode`. Перед сдачей вернуть обычный режим.
7. **Проверка** запуском `python3 -I scripts/check_test_site.py`. Ожидаем: в robots.txt есть `Disallow: /`, `/?p=1` даёт 301 на «красивый» URL, часовой пояс `Asia/Jerusalem`, тема `hello-elementor`. Результат вписать в журнал выше.

## Открытые вопросы

**От агентства** (из брифа):
- бриф клиента;
- логотип, цвета, фото;
- срок;
- кто утверждает дизайн;
- **бот uPress «סוכן וורדפרס»**: в открытой документации uPress не описан (research/04 §5.2), это главный риск для шага 3;
- **PHP 8.4**: WordPress 7.1 его поддерживает, у Elementor явного заявления нет; рекомендуем 8.3 или тест на 8.4 с логом ошибок.

**Новые, найденные в работе:**
- **REST API в uPress.** Может быть выключен в настройках безопасности, тогда Elementor MCP не заработает (research/04 §5.8). Решать с Олегом.
- Год начала надзора: нужен документ — лицензия или письмо министерства.
- Канонический адрес: на сайте только ת״ד 28 с устаревшим пятизначным индексом; в реестрах адреса расходятся.
- Кто «רכז נגישות»: его данные обязательны в הצהרת נגישות (research/05 §1.4).
- Согласия на фото жильцов: какие кадры можно использовать.
- Актуальный список сотрудников и ролей.
- Возрастной диапазон программы по аутизму; для кого рамка «מערך דיור» в отделе «שיקום ונכים».
- Есть ли волонтёры и пожертвования.

## Безопасность и правила

- **Секреты — только в `.env`**: он в `.gitignore`, шаблон — [.env.example](.env.example). `.mcp.json` тоже в `.gitignore`: туда Claude Code может записать токен MCP.
- На живой сайт отправлялись только GET-запросы для сбора контента.
- На тестовом сайте ничего не менялось. В панели uPress ничего не менялось.
- Никуда ничего не публиковалось и ни с кем не связывались.
- Фото жильцов с узнаваемыми лицами в прототипе не используются. У всех фото в прототипе удалены EXIF и GPS.
